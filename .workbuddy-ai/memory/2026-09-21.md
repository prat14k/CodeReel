## Environment gotchas hit today

- **`timeout` does not exist on macOS.** A `timeout 300 …` wrapper silently became
  `command not found` and the follow-up `echo exit=$?` reported 0 — a false green.
- **The sandbox PATH omits `/opt/homebrew/bin`**, so `ffmpeg` is "not found" even
  though it is installed; `demo.py --selfcheck` dies with
  `FileNotFoundError: 'ffmpeg'`. Prefix with
  `PATH="/opt/homebrew/bin:/usr/local/bin:$PATH"`.
- **Never run a scratch Python script out of `/tmp`.** Some other project left
  `/tmp/inspect.py` behind, and Python puts the *script's* directory first on
  `sys.path`, so it shadowed stdlib `inspect` and produced
  `AttributeError: module 'inspect' has no attribute 'get_annotations'` deep inside
  `dataclasses`. Use `PYTHONSAFEPATH=1` with `PYTHONPATH=<repo>`, or write the
  scratch file inside the repo.
